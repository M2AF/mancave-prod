# Visual Iteration Skill

## Trigger

Use this skill whenever:

* React UI is modified
* CSS is modified
* Electron UI is modified
* Layout changes are requested
* Visual defects are reported

---

## Process

### Step 1

Implement requested changes.

### Step 2

Launch application.

### Step 3

Capture screenshot.

### Step 4

Compare screenshot against requirements.

### Step 5

List all discrepancies.

### Step 6

Modify code.

### Step 7

Repeat until all discrepancies are resolved.

---

## Screenshot Review Checklist

### Layout

* Alignment
* Spacing
* Margins
* Padding

### Typography

* Font size
* Weight
* Contrast

### Components

* Buttons
* Forms
* Icons
* Images

### Visual Quality

* Clipping
* Overflow
* Scrollbars
* Z-index issues

### Responsive

* Desktop
* Tablet
* Mobile

---

## Success Criteria

The screenshot matches the requested design.

Code correctness alone is insufficient.
