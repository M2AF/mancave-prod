## Shared project bank

Every agent on this project shares these, so anything learned here helps the next one.

- **Memory:** read `.agents/memory/INDEX.md` before starting and open the topics that apply.
- **Skills:** task instructions are in `.agents/skills/<name>/SKILL.md`. Use the one that fits.
- **Current work:** who is doing what belongs in `HANDOFF.md`, not in memory.

To add to memory, append one line to `.agents/memory/<topic>.md` as `- YYYY-MM-DD (who): fact`, and list new topics in the index.

- Only record lasting facts you verified, not plans or status.
- Never record secrets, keys, or personal data. This folder is committed to git.
- Correct a wrong fact by editing it. Don't leave both versions.
