# Logos

All of these are in `assets/logos/`. They are the user's real logos. Never redraw, recolour, stretch or replace them.

| File | Use for | What to know |
|---|---|---|
| `mancave.png` | ManCave Productions | Blue house and doorway mark on solid white, 1254 x 1254, with a lot of empty margin. This logo sets the site's look. |
| `chainlens.png` | ChainLens | White link and magnifier in a circle on solid black, 1000 x 1000. |
| `magic-money.png` | Magic Money | Coin and wand mark with a white wordmark on a transparent background. The wordmark disappears on light backgrounds, so it needs a dark one. |
| `magic-money-icon.svg` | Magic Money | Icon only. Use where the wordmark would be too small. |
| `afterglow.png` | AfterGlow | Transparent logo. |
| `arcade/duo.png`, `poker.png`, `pool.png`, `swarm.png`, `clash.png`, `world.png` | The six games | Each game's own logo. Check each one on the final background. |

There is no ChainLens Arcade logo. Set the name "ChainLens Arcade" as styled text, using the ChainLens mark and game logos beside it. Don't invent a logo for it.

Allowed: trimming the empty margin from `mancave.png`, and making its white background transparent, saved as a new file with the original kept. Sample the exact blue from the logo instead of guessing it.
